# Исследование влияния регуляризации при обучении суррогатного оператора на качество обнаружения симметрий

Экспериментальный репозиторий магистерской работы. Рассматриваются пространственные симметрии операторов, отображающих начальное поле в решение уравнения диффузии в фиксированный момент времени.

## Цель

Выяснить, как вид и сила регуляризации влияют на способность суррогатного оператора восстанавливать симметрии исходной задачи при малой выборке и шуме в обучающих ответах.

**Гипотеза.** Регуляризация может снижать ошибку прогноза и при этом ухудшать обнаружение симметрий. Сильное сглаживание может ослабить пространственные различия, по которым различаются истинные и ложные кандидаты.

## Что уже реализовано

- Три синтетических эталона с аналитически известными симметриями — изотропная диффузия и два уровня анизотропии на периодической сетке.
- Линейная аппроксимация оператора на фиксированной сетке в трёх режимах — без регуляризации, с L2-штрафом и со штрафом за пространственные разности.
- Проверка семи преобразований квадрата по относительной норме коммутатора. Отдельно измеряются ошибка прогноза, ROC AUC, F1, ложные срабатывания и пропуски.
- Парный эксперимент на 20 случайных выборках с двумя объёмами обучения и двумя уровнями шума.

## Воспроизведение

Требуется Python 3.12 или новее. Проверено на Python 3.14. GPU и внешние данные не требуются. Запустите команды из корня проекта.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python experiment.py --quick --out results/quick
python experiment.py --out results/full
```

Полный запуск сохраняет таблицы, параметры расчёта и график в `results/full`. Быстрый запуск проверяет весь путь на двух случайных выборках. Для запуска на Windows активируйте окружение командой `.venv\Scripts\Activate.ps1` в PowerShell.
