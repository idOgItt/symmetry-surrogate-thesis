## Описание исследования

Поворот или отражение считается симметрией оператора решения, если преобразование начального поля даёт тот же результат, что и такое же преобразование уже вычисленного решения. Для приближённого оператора это свойство проверяется на независимых данных с помощью относительной нормы коммутатора.

**Цель работы** — установить, при каких размерах обучающей выборки и уровнях шума регуляризация помогает обнаруживать симметрии, а при каких затрудняет их обнаружение.

**Гипотеза** — точность прогноза и качество обнаружения симметрий по-разному зависят от регуляризации. Например, сильное сглаживание может ослабить признаки анизотропии и сблизить оценки истинных и ложных кандидатов.

В пилоте сравниваются линейные суррогаты без штрафа, с L2-регуляризацией и со штрафом за пространственные разности. Эталоны — изотропная диффузия и диффузия с двумя уровнями анизотропии на периодической сетке. Для каждого эталона проверяются семь поворотов и отражений квадрата. Относительная ошибка L2 измеряет точность прогноза, ROC AUC — качество ранжирования кандидатов, F1 — качество классификации при фиксированном пороге.

### Первый семестр · сентябрь 2026 — январь 2027

- Изучить методы операторного обучения, эквивариантность и поиск симметрий по данным.

- Подготовить протокол сравнения регуляризаторов, метрики и воспроизводимый запуск.

### Второй семестр · февраль — июнь 2027

- Сравнить базовый линейный оператор, L2-регуляризацию и сглаживание на нескольких уровнях шума и объёмах данных.
- Оценить чувствительность результатов к силе штрафа, порогу обнаружения и степени анизотропии.
- Разобрать ложные срабатывания и пропуски, выделить режимы, в которых ошибка прогноза и качество обнаружения меняются по-разному.

### Третий семестр · сентябрь 2027 — январь 2028

- Повторить сравнение для нелинейного суррогата, задач с переменными коэффициентами и нескольких разрешений сетки.
- Проверить перенос выводов на новые задачи и распределения начальных полей.
- Изучить применимость поиска непрерывных симметрий по обученному оператору на примере FINS.

### Четвёртый семестр · февраль — июнь 2028

## Воспроизведение

Требуется Python 3.12 или новее. Проверено на Python 3.14. GPU и внешние данные не требуются. Запустите команды из корня проекта.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python experiment.py --quick --out results/quick
python experiment.py --out results/full
```

Полный запуск сохраняет таблицы, параметры расчёта и график в `results/full`. Быстрый запуск проверяет весь путь на двух случайных выборках. Для запуска на Windows активируйте окружение командой `.venv\Scripts\Activate.ps1` в PowerShell.
