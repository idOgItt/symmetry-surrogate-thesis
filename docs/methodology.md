# Методика пилотного эксперимента

## Эталон и кандидаты

Начальное поле $u$ задано на периодической сетке $9\times9$. Эталон $F$ возвращает решение в момент $t=1$ для дискретного уравнения теплопроводности

$$
\partial_t u = -a_y L_y u - a_x L_x u.
$$

Здесь $L_y$ и $L_x$ — положительные операторы вторых разностей с шагом 1. Точный шаг по времени для этой дискретизации умножает каждую пространственную частоту на $\exp[-t(a_y\mu_y+a_x\mu_x)]$, где $\mu_k=4\sin^2(\pi k/9)$.

| Задача | $(a_y,a_x)$ | Истинные симметрии среди кандидатов |
| --- | --- | --- |
| Изотропная | $(0.65,0.65)$ | Все семь |
| Слабая анизотропия | $(0.55,0.75)$ | Поворот на 180° и два осевых отражения |
| Сильная анизотропия | $(0.2,1.1)$ | Поворот на 180° и два осевых отражения |

Проверяются три поворота (90°, 180°, 270°) и четыре отражения (два осевых и два диагональных). В каждой анизотропной задаче ровно четыре преобразования меняют оси местами и являются отрицательными кандидатами. Тождественное преобразование исключено из оценки. Список симметрий следует из действия преобразований на пространственные разности. Эталон дополнительно проверяется численно на тестовых входах.

## Обучение

Входы — независимые гауссовские периодические поля с фильтром спектра $(1+\mu_x+\mu_y)^{-1}$. Матрицы $X$ и $Y$ содержат развёрнутые поля по строкам. Суррогат $A(u)=uW$ обучается минимизацией

$$
n^{-1}\lVert XW-Y\rVert_F^2
 + \alpha\lVert W\rVert_F^2
 + \beta\operatorname{tr}(W L W^\top),
\qquad L=L_x+L_y.
$$

Последний член штрафует квадраты пространственных разностей каждой строки $W$, рассматриваемой как поле на выходной сетке. Штраф задаёт предпочтение гладким откликам. В функции потерь отсутствуют размеченные кандидаты, преобразованные пары и штраф за коммутатор.

Базовый режим использует решение наименьшей нормы. Для ridge берётся $\alpha=\lambda$, для сглаживания $\beta=\lambda/8$, остальные коэффициенты равны нулю. Число 8 ограничивает спектр $L$ сверху, поэтому силы сравнимы по максимальной добавке к знаменателю решения. Значения $\lambda$ равны 0.003, 0.03 и 0.3. Разложение $X$ по SVD и диагонализация $L$ позволяют решить задачу без итерационного оптимизатора.

На каждом из 20 seed генерируются 96 обучающих и независимо 256 тестовых полей. Для меньшего объёма берутся первые 24 обучающих поля. В обучающих ответах сравниваются уровни шума 0% и 20%. Шум — независимый по ячейкам стандартный нормальный шум, умноженный на выбранный уровень и RMS чистых ответов текущего обучающего набора. Внутри seed методы используют одинаковые входы и одинаковые реализации шума. Для оценки используются чистые тестовые ответы.

## Обнаружение

На независимой выборке $X_{test}$ для каждого кандидата $g$ вычисляется

$$
r(g)=\frac{\lVert A(g X_{test})-g A(X_{test})\rVert_F}
{\lVert A(X_{test})\rVert_F}.
$$

Меньший остаток означает более высокую оценку правдоподобия симметрии. Чтобы посчитать ROC AUC, для каждого seed объединяются 21 кандидат из трёх задач. Из них 13 положительных и 8 отрицательных. AUC сравнивает все пары положительного и отрицательного кандидатов, начисляя половину балла за совпадение. Для F1 и числа ошибок используется фиксированный порог $r\leq 0.2$, одинаковый для всех режимов. Дополнительно сохраняется зазор между минимальным остатком отрицательного и максимальным остатком положительного кандидата. Положительный зазор означает, что существует порог, разделяющий все кандидаты в этом прогоне.

Ошибка прогноза — относительная норма Фробениуса между суррогатом и чистым тестовым ответом. Для сводки берётся среднее трёх задач. Разности с базовым режимом вычисляются внутри каждого seed. Для средних разностей приводится 95%-й процентильный интервал парного бутстрэпа по seed (4000 повторов, seed 618). Оценки описывают вариабельность между выборками для этих трёх фиксированных эталонов. Поправка на множественные сравнения не применяется.

## Файлы запуска

| Файл | Одна строка |
| --- | --- |
| `runs.csv` | Один seed, объём, уровень шума и вариант регуляризации с метриками прогноза и обнаружения |
| `symmetry_scores.csv` | Один кандидат в одной задаче с истинной меткой и остатками суррогата и эталона |
| `summary.csv` | Один режим с агрегатами по seed и парными разностями с базовым режимом |
| `metadata.json` | Параметры эксперимента и версии Python, NumPy и Matplotlib |
| `overview.png` | Средние значения метрик по режимам, с базовым уровнем в каждой панели |

Эксперимент ограничен тремя линейными эталонами, фиксированной сеткой и конечным набором кандидатов. Проверка коммутатора на конечной выборке даёт эмпирическую оценку. В постановке с неизвестным набором симметрий потребуется также поиск кандидатов.
